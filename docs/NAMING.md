# Naming: Forage, forage.fyi, and the `/f/` convention

**This file is canonical** for why this project is called what it is, what was
rejected, and what clearance was actually done. It was promoted out of one session's
agent memory on 2026-08-26 — where it was unversioned, invisible to peer sessions, and
would have died with the machine. If you are about to re-open the naming question, or
wonder whether a name is safe to use, this is the record.

## The name

**Forage**, at **forage.fyi**. Members are **foragers**.

Forum paths use the **`/f/` convention** — `forage.fyi/f/gardening`, reddit-style. The
letter carries double duty: **f** for forum and for forage. Route shapes depend on this
prefix, so changing it is a breaking change to every shared link (and the `/f/` route
block is order-dependent — see `test/routes.test.js`).

## What was rejected, and why

Both first choices were taken, and the record matters because they read as obvious and
will be proposed again:

- **graze** — taken. Graze is the bsky feed-builder company; using it would collide
  directly inside the atproto ecosystem, which is the worst place to collide.
- **amble** — also taken.

The brief that produced all three was the croft/drystone one: quiet, unhurried,
land-shaped words.

## Trademark and ecosystem clearance (2026-08-21)

Done before purchase, recorded so it does not have to be redone from scratch:

- **No live FORAGE trademark in the social/software classes.** The two Forage, Inc.
  software marks are **dead**. The theforage.com edtech mark is live but covers
  **career-placement services only** — a different class.
- **Nothing in the atproto ecosystem list** using the name.
- **No social-network incumbent.**

Clearance is a point-in-time finding, not a permanent guarantee. It was true on
2026-08-21; a fresh check is warranted before any trademark filing or a significant
brand spend.

## Brand-world material explored but not adopted

Available if the identity ever wants more depth:

- **Raven mythology** — ravens forage socially and recruit others to food at the roost
  (Heinrich). A genuinely apt metaphor for a forum: finding is social, and sharing the
  find is the behaviour.
- **"Rookery"** — **contested**: rookery.network is a live "social media for research
  papers" project. Do not treat this as free.
- **"Nevermore"** as an anti-enshittification charter name — **tagline only**. Netflix's
  Nevermore Academy owns the trademark space; it cannot be a product name.

## Defensive registrations NOT held

Deliberately not purchased, listed so nobody assumes they are ours: `graze.fyi`,
`forage.rs` (would have been nice for "foragers"), `forage.exchange`, `forage.place`.
Already taken by others: `fora.ge`, `forage.app`.

Registrar and renewal details are operator-local and deliberately not in this repo; the
one thing worth stating publicly is that **forage.fyi is a premium registration and
premium lapses get sniped**, so the renewal is not a routine one to let slide.
