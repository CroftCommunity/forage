The stage rule

  • Frame = card width; height = min(stage cap, picture's natural height at that width). A small landscape photo never gets stretched; a tall portrait never exceeds the cap.
  • Backdrop = the same picture, blur(22px) brightness(.55), scaled 115% so the blur has no edge. Video: black bands instead (a moving blur is noise).
  • Tap = opens full size (image) or bsky.app (video), as today. The stage is one link; the arrows and dots are buttons inside it.
  • Compact rows keep the 40px thumb — nothing here changes compact.

Carousel / grid

  • Setting N (1–4, default 1): ≤ N pictures → grid (2 side by side · 3 = one tall + two · 4 = 2×2, Bluesky's own shapes); > N → carousel. The sample post above has four pictures, so it is a carousel until the setting reaches 4.
  • Carousel: dots, edge arrows (desktop), swipe (phone), ← → when focused, aria-live “picture 2 of 3” for a screen reader, the counter top-right.
  • Each slide keeps its own alt; a slide without alt is named “picture n of m, opens full size”.

It is content, not commerce: a sign-in card for a guest (the ring pitch that already lives in the nav note), three feeds you might like, trending tags — the same sources lensSidebar already draws. F — pinned

  • .masthead is already position: sticky but sits in a #masthost wrapper exactly its own height, so it scrolls away. The wrapper takes the sticky (or display: contents); the dev bar is unpinned. mobile-fit gains “masthead top is 0 after a scroll”.
